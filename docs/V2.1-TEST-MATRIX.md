## Tests fonctionnels minimum

1. Ouvrir la Table Antique 4x4.
2. Vérifier preview + craft simple d'une recette existante.
3. Vérifier shift-craft existant (comportement inchangé en V2.1).
4. Vérifier craft vanilla custom via l'extension KHope actuelle.
5. Vérifier une recette CIT/NBT.
6. Vérifier `/kcraft reload`.
7. Vérifier Kjobs après craft: `KcraftPostCraftEvent` doit toujours être reçu.

## Tests du validateur

Sur serveur de test uniquement, provoquer puis annuler chacun de ces cas:

- `schema_version: 1` => boot refusé.
- `size: 9x9` => boot refusé.
- recréer un bloc racine `gui:` => boot refusé.
- mettre un matériau inexistant dans blocked-generated-loot => boot refusé.
- recette avec table inconnue => validation recettes refusée.
