## Démarrage

```text

```

## Baseline

Juste après démarrage :

```text
/kcraft perf
```

Les compteurs activité doivent être proches de zéro.

## Charge manuelle

1. ouvrir une table custom ;
2. bouger plusieurs stacks rapidement ;
3. effectuer plusieurs crafts ;
4. faire un shift-craft ;
5. attendre un flush logging ;
6. poser/casser plusieurs tables.

Puis :

```text
/kcraft perf
```

À relever :
- candidates avg ;
- exact avg ;
- matching avg/max us ;
- GUI coalesce rate ;
- batch planning avg/max ;
- logging dropped doit rester 0 ;
- failures doit rester 0 ;
- table persistence failures doit rester 0.
