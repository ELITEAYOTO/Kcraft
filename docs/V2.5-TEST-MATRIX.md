# KCraft V2.5 — Tests

## Build

```powershell
mvn clean package
git diff --check
git status --short
```

Attendu : tests historiques + V2.3 + V2.4 + nouveaux tests V2.5.

## DirtyQueue

Dans une table custom :
- déplacer rapidement plusieurs stacks ;
- drag ;
- shift-click inventaire.

Le preview doit suivre correctement sans retard permanent.

## Preview lock random

Avec une recette à plusieurs résultats :
1. placer les ingrédients ;
2. noter l'item affiché ;
3. cliquer craft ;
4. vérifier que l'item reçu est exactement celui affiché.

Refaire plusieurs fois pour confirmer.

## Modification de grille sans changer de recipe

Si la même recette reste valide (par exemple quantité de stack change),
la preview reste volontairement stable jusqu'à une vraie tentative.

## Changement de recipe

Passer d'une recette A à une recette B :
- le lock A doit être abandonné ;
- une nouvelle preview B doit apparaître.

## Close / reopen

Fermer la GUI avant le prochain flush :
- aucune erreur ;
- aucun refresh stale ;
- ingrédients restitués normalement.
