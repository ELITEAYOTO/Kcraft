# KCraft V2.3 — Test Matrix

## Build

```powershell
mvn clean package
git diff --check
git status --short
```

## Boot attendu

```text
Kcraft V2.3
CompiledRecipe V2.3 prêt - recipes=112 ...
RecipeIndex V2.3 prêt - recipes=112, buckets=..., avgBucket=..., maxBucket=...
Kcraft V2.3 actif ...
```

Le nombre de recettes indexées doit être 112.

## Fonctionnel custom table

Tester au minimum :

1. SHAPED simple ;
2. SHAPED décalé dans 4x4/5x5 ;
3. SHAPED mirror si une recette l'utilise ;
4. SHAPELESS ;
5. ingrédient amount > 1 ;
6. data value 1.8 ;
7. CIT / `sparrowmc-item` ;
8. nom/lore ;
9. strict-material.

## Vérification clé

Preview doit fonctionner SANS consommation.

Le clic réel doit continuer à consommer via la transaction existante.

## Reload

```text
/kcraft reload
```

Doit reconstruire :

```text
CompiledRecipeCatalog
RecipeIndex
```

sans restart.
