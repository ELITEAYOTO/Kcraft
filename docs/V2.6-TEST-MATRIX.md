
## Legacy context

Pendant le même batch, tous les `KcraftPostCraftEvent` doivent avoir :

```text
source=SHIFT_BATCH
même transactionId
batchIndex différent
```

## API mutation

Si utilisée :

```text
registerCraft
-> Recipe runtime V2.6 reconstruit
-> compiled/index incluent immédiatement la recipe

unregisterCraft
-> même rebuild
```
