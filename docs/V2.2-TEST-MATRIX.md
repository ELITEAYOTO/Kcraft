# KCraft V2.2 — Test Matrix

## Build

```powershell
mvn clean package
git diff --check
git status --short
```

## Tests Maven

Tous les tests V2.1/V1 doivent rester verts.

## Boot

Attendu :

```text
Kcraft V2.2
Validation V2 OK - 112 recette(s), 3 table(s)
CompiledRecipe V2.2 prêt - recipes=112, ...
Kcraft V2.2 actif - recipes=112, tables=3, compiled=112, ...
```

Le nombre `compiled` doit être exactement égal au nombre de recettes valides.

## Reload

```text
/kcraft reload
```

Attendu :

```text
CompiledRecipe reload - recipes=112, ...
Kcraft V2.2 rechargé - recipes=112
```
