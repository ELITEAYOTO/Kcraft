# V2.3.1 — Lazy ItemMeta Fix

Le code production V2.3 compilait correctement.

Les tests échouaient car `ItemSnapshot` appelait `ItemStack.hasItemMeta()` lors
de la capture de chaque slot.

Dans Bukkit 1.8, cette méthode appelle `Bukkit.getItemFactory()`. Un test JUnit
pur ne démarre pas CraftBukkit, donc l'ItemFactory est `null`.

La correction est aussi une optimisation :

```text
avant
chaque ItemSnapshot
 -> Bukkit ItemFactory
 -> ItemMeta
même si la recette ne vérifie pas name/lore

après
Material/data/amount immédiatement
ItemMeta seulement si requiresName/requiresLore
NBT seulement si nécessaire
```

Ainsi une recette purement Material ne touche ni ItemMeta ni NBT.
