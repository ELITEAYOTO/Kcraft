# KCraft V2.4 — Test Matrix

## Build

```powershell
mvn clean package
git diff --check
git status --short
```

## Boot

Attendu :

```text
Kcraft V2.4
CompiledRecipe V2.4 ...
RecipeIndex V2.3 prêt ...
Kcraft V2.4 actif ...
```

Le RecipeIndex garde son nom V2.3 : il n'a pas été modifié dans cette phase.

## Shift craft

Tester une recette simple avec plusieurs crafts possibles :

- 2 crafts
- 10 crafts
- limite 64

Attendu :

- quantité finale exacte ;
- résultats exacts ;
- aucun item dupliqué ;
- aucun ingrédient négatif ;
- message mass-success avec le nombre réellement réussi.

## Success rate <100 %

Le batch doit s'arrêter au premier échec, comme l'ancien comportement.

Si `return-items-on-fail: false`, les ingrédients du craft échoué sont consommés.

## SHAPELESS

Tester si possible une recette shapeless avec plusieurs stacks du même
Material : le planner peut réaffecter les ingrédients entre les crafts.

## CIT/NBT

Tester un batch CIT pour confirmer que les contraintes restent identiques.

## Important

V2.4 simplifie volontairement CraftGUIListener et ne simule plus de recipes
vanilla dans la GUI custom (`findVanillaCraftResult` était déjà TODO/null).
